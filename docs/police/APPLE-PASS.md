# Police: the Apple pass (2026-10-07)

The same treatment DPP and Lawyers had, in Police's own words. The test for every screen, before anything is added or moved: **how would Apple organise this, arrange it, and name it?** One place per thing, one blue action per screen, names a person uses (never a table or field name), nothing shown that has no work behind it, and every record readable as a document, not a form.

## Done

- **Window:** transparent rounded window, Mac window buttons and the sidebar button top left; ribbon and status bar removed; Safari-like tabs; translucent title bar. Works in the desktop window and in a browser.
- **Sidebar** (approved by the user 2026-10-07): Today, Station diary, Incidents, People, Documents / Cells: In custody (red count only near the 48 hours), Police bonds / Cases as folders: Under investigation, With the DPP, Closed, All cases / Case papers: Statements, Exhibits, Charge sheets, Referrals / Station: Officers, Duty roster, Vehicles, Armoury, Impounded property, Statistics. Footer: the officer, language, Settings, sign out. Station profile, the backup log and remote access open from Settings.
- **Cases:** Case intake, Investigations and Case files were three doors to the same cases; now one Cases page by folder, one "Open a case" button. `/intake` redirects.
- **Today** (was Overview): date, one action (New diary entry), a red "Cannot wait" box only when someone is near or past the custody limit or an officer is calling for backup, figures only when not zero, referrals waiting for a reply, what just happened.
- **Documents** (was the "Police Vault" file manager with paths, MIME types and IDs): folders by case, person and register under officers' names (a person's folder shows the person's name), files under their record's own title, newest first. Every file opens inside the app (photos, PDF, Markdown as a paper sheet, text) with Print; links between notes open in the same viewer; "Open in another program" and "Show in folder" are in the "···" menu only. New Rust: `read_vault_file`, vault entries carry `title` and `item_count`.

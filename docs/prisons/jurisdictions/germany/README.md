# Germany jurisdiction pack — the boundary, not a config

`research`. **There is no single German prison law.**

Prison law (Strafvollzug) is primarily **Land** law — 16 federal states each legislate enforcement of sentences — on a federal frame (the StVollzG and StPO for remand, the EU-prison-rules-derived minimums). A "German Germany pack" is not buildable as one unit and attempting a fake single configuration would be the exact invention `JURISDICTIONS.md` forbids.

- German UI locale (`../LOCALIZATION.md`) does not imply German law.
- This page tracks any concrete Land statutes read, each with its citation, before anything is `designed`.
